## M1 防护验收

在自有授权逻辑中，用受控替身返回成功结果，确认产品能独立执行以下拒绝条件。验收读取持久状态、凭据存储、授权缓存和实际下游调用，结果归入产品 IAM-02。

| 场景 | 验收结果 |
| --- | --- |
| 授权尚未完成，用户已停用该次授权 | 晚到的回调不能完成旧授权或保存凭据。开始一次新的连接需要用户显式授权。 |
| 停用时已有刷新在途 | 旧刷新结果即使为成功，也不能写回凭据、恢复授权或放行等待作业。服务重启后仍执行这一边界。 |
| 停用后显式重新授权，旧结果晚到 | 只接受当前那次授权的结果，旧回调和旧刷新均不得覆盖新凭据。 |
| 同一用户的其他授权、同一应用的其他用户 | 独立授权及身份登录保持可用；只保留脱敏的拒绝原因与操作关联。 |

产品端根据当前授权记录及其版本决定是否接受结果，并在保存结果时同时检查授权状态与版本。已发往上游的操作保留回执，未知结果按既有规则只读对账。产品侧停用、原生授权列表状态和上游凭据状态继续分别报告。以上为待实现的验收条件，G06 的公开单用户自动撤销缺口及两项上游待验状态保持。 [既有撤销边界](../adr/0003-gitea-authorization-profiles.md#2026-11-09-单用户-grant-撤销边界)
