## M0-G19 · 草稿权限

- **已有实测。** 私有仓库所有者持 `resource_read` 时，草稿列表排除目标，按 ID 的详情返回 404。已知的 UUID 和仓库 / Tag / 文件名两条下载路径均返回 200，UUID 路径核对了原始字节。普通写者降为读者后两条草稿附件路径均被拒绝，已发布内容仍可读。外部用户的直接 UUID 下载被拒绝，匿名请求得到登录回执。 [原批权限与差异](2026-11-04-m0-release-validation.md#主路径与权限)
- **按 ID、列表与附件元数据。** `canAccessReleaseDraft` 要求登录和当前 Release 单元写权限。带 Token 时还要求仓库写 scope。按 ID 不满足条件返回 404，列表排除草稿，REST 附件列表 / 单项元数据复用同一草稿门槛。 [草稿鉴权与按 ID 查询](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/api/v1/repo/release.go#L22-L86) · [列表过滤](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/api/v1/repo/release.go#L173-L185) · [附件元数据门槛](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/api/v1/repo/release_attachment.go#L23-L42)
- **附件字节。** UUID 路径直接进入 `ServeAttachment`。按 Tag / 文件名路径按仓库查找 Release，以用户的 Release 单元写权限决定是否包含草稿，定位附件后进入同一处理器。`ServeAttachment` 检查关联仓库、单元读取权限及草稿所需的单元写权限，Release 附件的 Token 门槛则是 `read:repository`。这解释了所有者持只读 Token 仍可下载的实测结果。 [UUID 与名称下载路由](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/web/web.go#L1497-L1513) · [Tag / 文件名查找](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/web/repo/repo.go#L302-L329) · [下载 scope](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/web/repo/attachment.go#L25-L34) · [下载对象权限](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/web/repo/attachment.go#L146-L210)
- **新增待证入口。** REST `GET /repos/{owner}/{repo}/releases/tags/{tag}` 经过仓库 GET 的读取 scope 门槛。处理器另查登录与 Release 单元写权限，未使用草稿写 scope 门槛。按静态请求链，具有单元写权限的所有者持 `read:repository` 可能取得草稿元数据，响应还可能带说明和附件信息。此前按 Tag 回查使用写用途，本批未实测只读组合，归入 G19 补证。 [按 Tag 处理器](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/api/v1/repo/release_tags.go#L45-L74) · [GET scope 门槛](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/api/v1/api.go#L326-L358) · [返回字段](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/services/convert/release.go#L14-L34)

## M0-G20 · 空字段清除

- **已有实测与公开接口。** 对有非空标题及说明的同一草稿提交 `PATCH {"name":"","body":""}` 得到 200，随后按 ID 回读，两项原值均保留。固定 OpenAPI 的 `EditReleaseOption` 将两个字段声明为字符串。处理器仅在长度大于零时赋值，再更新 Release、重新读出对象并返回。省略字段和显式空字符串都不会触发赋值，固定公开 Release API 未找到清除已有字段的独立操作。 [原批差异](2026-11-04-m0-release-validation.md#保留的五项差异) · [字段定义](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/modules/structs/release.go#L64-L78) · [更新处理器](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/api/v1/repo/release.go#L348-L394) · [REST 路由](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/api/v1/api.go#L1465-L1486)
- **原生页面候选。** 已登录且有 Release 写权限的用户可在原生页面编辑。表单要求去除首尾空白后的标题非空，说明字段可为空，处理器把表单说明直接写入原 Release。草稿页面提供独立的保存草稿按钮，使用发布按钮会改变状态。手动清空说明是待实测候选，需对原 ID 回读字段与状态。页面表单属于原生交互契约，公开自动清除缺口仍保留。 [表单字段](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/services/forms/repo_form.go#L550-L558) · [页面更新处理器](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/routers/web/repo/release.go#L576-L629) · [草稿保存按钮](https://github.com/go-gitea/gitea/blob/829b49c1ae96015e345f9d2a0eb1ea7acd5f31e1/templates/repo/release/new.tmpl#L120-L135)
