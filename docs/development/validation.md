# 验证分层

当前已有文档与治理检查器及其回归测试，以及[M0 本机真实上游探针](../../tests/contracts/m0/README.md)；没有可运行的自有产品、业务测试套件或活动 CI。已有上游部分证据与产品验收分开，下面各层按实际范围取证。

| 层级 | 范围 | 证据 |
| --- | --- | --- |
| 文档 | 链接、任务与验收编号、状态一致、来源日期、根入口同步 | 本地文档检查记录 |
| 单元 | 权限决策、状态转换、Digest / 清单解析、去重与重试策略 | 独立输入与预期，覆盖失败边界 |
| 集成 | PostgreSQL 事务 / 租约、迁移、密钥使用、HTTP 超时与恢复 | 隔离实例版本及结果 |
| 上游契约 | 真实 Gitea / Runner 的 OAuth、Issue、Actions、Packages、Release | 固定版本、请求响应脱敏样例 |
| UI | 从登录到 Issue / 发布 / 部署的交互、键盘、窄屏和错误态 | 浏览器操作记录，不只静态截图 |
| 交付 | 干净安装、镜像来源、升级、迁移失败、备份恢复、权限隔离 | 实际镜像 Digest、数据批次和演练结果 |

## 推进粒度

日常开发只运行受影响检查；通过后除非有新改动或未解决风险，不重复扩大。阶段晋级覆盖已完成能力的真实主路径及关键失败。发行增加安装、备份、恢复、升级与权限边界，不能仅以单元测试替代。

Mock 用于确定性失败注入，但不证明真实底座协议；构建通过不证明服务可用。契约测试需包含 401 / 403、过期 Token、资源删除、分页、限流、超时和部分写入。权限用两个隔离用户及组织验证，不能只测管理员。

## 证据模板

记录日期、任务 / 验收 ID、源码提交、组件版本 / Digest、宿主平台、数据范围、执行命令或步骤、预期、实际、附件引用、未验证项、资源清理与失败后状态。尚无 Git 时直接说明，没有证据不能填写通过。

发布 / 部署结果未知必须记录并先对账，不能把进程返回成功当作远端完成。CI 门禁只能聚合实际存在并成功的检查，缺失、跳过或取消不是成功。

治理检查入口见[scripts](../../scripts/README.md)，覆盖真实文件与模板契约，并用故障变体验证拒绝行为。无 Git 时明确 Git 检查未运行；无远端时不声称 Rulesets 生效。同一 unittest 入口还包含 M0 完整 scope 组合的本地负例；治理和 M0 策略测试均不是 Go 产品单元测试，也不替代真实授权证据。

本机上游探针退出 0 / 1 / 2 分别表示所执行用例未发现差异 / 执行中断 / 流程完成但存在差异；发现 scope 扩权等缺口仍以非零退出，不因其他用例通过关闭验收。记录请求轨迹时去掉查询参数、请求体、cookie 和 Token，运行私密数据与正式证据分开，清理后读回确认任务资源已移除。2026-11-01 的[本机记录](../records/2026-11-01-m0-local-validation.md)只覆盖上游身份、权限与 Issue 部分，不证明工作台真实浏览器交互、账号绑定或部署。

后续[授权组合记录](../records/2026-11-01-m0-auth-profile-validation.md)分别保存 `profiles` 的两项生命周期差异和 `discovery` 回归的三项原始 scope 差异，两者均退出 2。受控客户端约束通过不等于原始上游差异已修复；API 的无 cookie 传输与独立登录会话亦不能替代真实浏览器验收。

[2026-11-04 生命周期切片](../records/2026-11-04-m0-lifecycle-validation.md)对照旧配置 `lifecycle-baseline` 与受控 `lifecycle`，区分 introspection 参数被通用鉴权提前处理、客户端错误和账号拒绝。新批次包含实际配置回读、真实长时到期、一次并发 / 后继权限及原生单用户撤销，逐项按实际结果登记。原生页面只用于真实撤销取证，文件标记只协调时点，不作私有接口适配或模拟成功；25 秒内核对刚刷新 Token，避免把自然过期当成撤销。共享协议代码提取后回归原 `profiles`；本地 metadata / 网络未知拒绝负例与真实上游证据分别报告。

[同日 Issue 切片](../records/2026-11-04-m0-issue-validation.md)使用 `--mode issues`，按固定普通用户 / 角色 / 仓库验证列表与分类、正文版本、撤权和删除；非法输入原始结果与本地前检分开。请求出错也回读副作用，不能将 500 当作未写入。超时用本任务短时 TLS 监听真实扣留响应，分别记录上游已写入 / 未转发、客户端 TimeoutError、只读回查与零自动重试；零条或多条匹配都保持 unknown。35 项本地测试只证明本地决策 / 失败边界，三批真实结果仍保留差异并退出 2，不混同为产品或完整 M0 通过。

[接续 Release 切片](../records/2026-11-04-m0-release-validation.md)新增独立用途与显式原始 bytes，用真实附件长度 / SHA-256 核对内容，分别验证元数据和两种下载路径的权限。共用注入按精确操作限制创建 POST / 发布 PATCH / 附件 POST：三类已提交响应丢失和未转发均真实超时，另有半包断开与同名多匹配；只读回查、零自动重试。48 项本地测试与最终三个真实流程分开，后三者分别保留 5 / 12 / 1 条差异退出 2；前三个中断批次也保留退出 1、只读诊断和已执行源码，不删标记重放或把 URL / 状态码修正冒充上游原始结果改变。

[OCI 切片](../records/2026-11-04-m0-oci-validation.md)区分标准库有界协议、Docker build / save / load 和真实 regctl 推拉；按原始 Manifest / config / layer bytes 核对 Digest，权限负例直接访问 Registry。上传开始没有 Location、只观察到 Range 前缀及半包后零完整对象均保持 unknown，回查仅 GET / HEAD，零自动重试；不以不存在对象替代撤权证明。63 项本地测试只证明本地边界；四项 OCI 差异和旧共享差异继续非零退出。Registry metadata 的 24 小时声明不代替真实到期，固定 Digest 不代替保留验收，健康 CLI 传输不代替其故障重试验收。

M0-S04 同源 REST 对照复用固定 Git 引用和附件。Gitea 探针的两个差异退出 2，GitHub 参考包含所有者及匿名。独立的 GitHub PAT 探针分别验证所有者凭据的只读范围和删除后拒绝，其退出 0 表示相应模式完成，退出 1 保留中断原因。GitHub 普通协作者的角色变化和撤权另行验证。G27 的短测仅观察单次换发与后继的读取和开启上传，真实到期保留为独立用例。 [同源 REST](../records/2026-11-09-m0-gitea-rest-comparison.md) · [所有者 PAT](../records/2026-11-09-m0-github-owner-pat.md) · [G27 换发](../records/2026-11-09-m0-registry-bearer-reissue.md)
