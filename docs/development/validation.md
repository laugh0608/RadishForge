# 验证分层

当前已有文档与治理检查器及其回归测试；没有可运行产品、业务测试套件或活动 CI。治理可本地验证，下面的业务层级仍是未来契约。

| 层级 | 范围 | 证据 |
| --- | --- | --- |
| 文档 | 链接、任务与验收编号、状态一致、来源日期、根入口同步 | 本地文档检查记录 |
| 单元 | 权限决策、状态转换、Digest / 清单解析、去重与重试策略 | 独立输入与预期，覆盖失败边界 |
| 集成 | PostgreSQL 事务 / 租约、迁移、密钥使用、HTTP 超时与恢复 | 隔离实例版本及结果 |
| 上游契约 | 真实 Gitea / Runner 的 OAuth、Issue、Actions、Packages、Release | 固定版本、请求响应脱敏样例 |
| UI | 从登录到 Issue / 发布 / 部署的交互、键盘、窄屏和错误态 | 浏览器操作记录，不只静态截图 |
| 交付 | 干净安装、镜像来源、升级、迁移失败、备份恢复、权限隔离 | 实际镜像 Digest、数据批次和演练结果 |

## 推进粒度

日常开发只运行受影响检查；通过后除非有新改动或未解决风险，不重复扩大。阶段晋级覆盖已完成能力的真实主路径及关键失败。发行增加安装、备份、恢复、升级与权限边界，不能仅以单元测试替代。

Mock 用于确定性失败注入，但不证明真实底座协议；构建通过不证明服务可用。契约测试需包含 401 / 403、过期 Token、资源删除、分页、限流、超时和部分写入。权限用两个隔离用户及组织验证，不能只测管理员。

## 证据模板

记录日期、任务 / 验收 ID、源码提交、组件版本 / Digest、宿主平台、数据范围、执行命令或步骤、预期、实际、附件引用、未验证项、资源清理与失败后状态。尚无 Git 时直接说明，没有证据不能填写通过。

发布 / 部署结果未知必须记录并先对账，不能把进程返回成功当作远端完成。CI 门禁只能聚合实际存在并成功的检查，缺失、跳过或取消不是成功。

治理检查入口见[scripts](../../scripts/README.md)，覆盖真实文件与模板契约，并用故障变体验证拒绝行为。无 Git 时明确 Git 检查未运行；无远端时不声称 Rulesets 生效。检查器测试不是产品单元测试。
